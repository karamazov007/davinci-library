## The tree

### D1 — The logic of weekly sets, frequency & rest
- ● **D1·1** — Volume is the growth *dose*: hard sets per muscle per week. Landmarks — ~6 maintain (MV), ~8–10 minimum (MEV), ~12–20 productive (MAV), ~20–25+ backfires (MRV).
  - ● **D1·1a** — What makes a set "count": ~0–4 RIR (effective reps near failure, full ROM, target muscle) + junk volume = far from failure / cheated / warm-ups.
    - ● **D1·1a.1** — RIR vs effective reps reconciled: RIR is counted *from* failure, so stopping at 0–4 RIR means you reached *into* the last-few-reps zone. Same reps, two descriptions.
    - ● **D1·1a.2** — Working default = **~2 RIR** (best for a beginner: banks most effective reps, protects form, manages fatigue).
    - ● **D1·1a.3** — Count RIR from **technical failure** (where form/ROM breaks), not ugly-grind failure. Broken reps aren't effective anyway → leave the ugly reps in the gym.
    - ● **D1·1a.4** — Don't fail on set 1 — it crashes later sets (8→6→6). 2 RIR gives more total quality volume (10→9→8). First working set at 2 RIR = your ceiling-finder (ceiling ≈ reps + 2); beat it over weeks, then add load (→ ties to D1·2a).
    - ● **D1·1a.5** — RIR *calibration* (how do you know it's 2 and not 4?): novices under-rate effort, so estimates are shaky at first. Fix by (i) occasionally hitting **technical failure on safe lifts** (machines/isolations, never heavy free-weight compounds) to feel the edge; (ii) reading the **involuntary bar-speed slowdown** as the primary cue — "could I do another rep at this same speed?"; (iii) testing the form-break line directly; (iv) letting the **logbook** objectively correct you over weeks. When unsure between 2 and 4, do one more.
    - ● **D1·1a.6** — Failure = a scalpel, not a default (unambiguous effort + max effective reps + best calibration, BUT big fatigue, slow recovery, degrades later sets/sessions, injury risk on compounds; not needed for growth, harmful every-set). Two methods: **A** = calibration/failure set — but place it **LAST, not first** (a first failure set pre-fatigues the rest so the rep target won't transfer), safe lifts only, technical failure/1 RIR is enough. **B** = autoregulate every set by loss-of-control/bar-speed, stop ~2 RIR. **Verdict: B is the everyday driver (esp. compounds); A occasionally as a safe finisher on machines/isolations.**
- ● **D1·2** — Volume climbs with training age: beginner ~10 → intermediate ~12–18 → advanced ~15–22+. Why: today's growth dose becomes tomorrow's maintenance dose (MEV drifts up). Add *reactively*, when progress stalls.
  - ● **D1·2a** — Volume progression across a **mesocycle**: start ~MEV, add ~1–2 sets/muscle/week, ramp toward MRV, then deload, then repeat. (Your model was essentially right.)
    - ● **D1·2a.1** — MRV is **symptom-detected, not scheduled**: ramp until performance drops / soreness won't clear / sleep-appetite-mood dip / dread — that's the deload signal. Block length (~4–6 wk) is an output.
    - ● **D1·2a.2** — Your "week 3 = ideal" ≈ **MAV** = the productive volume just below breakdown. Good heuristic, but MAV is a shifting *range*, not a fixed number.
    - ● **D1·2a.3** — **Deload** = cut volume hard (~to MV, ~half sets) + ease intensity, ~1 week → dissipate fatigue, supercompensate.
    - ● **D1·2a.4** — Correction: next block you **don't return to the same numbers** — MEV/MAV/MRV all drift **up**, so you restart higher and exceed the old ceiling. That upward drift block-over-block *is* long-term progress.
    - ● **D1·2a.5** — **Beginner caveat:** don't chase MRV yet. Sit in a good MAV volume (~12–16 sets for a priority muscle) and progress **load** (double progression); deload when stale. MRV-probing is an intermediate/advanced tool for when load progression stalls.
- ● **D1·3** — Frequency ~2×/wk beats 1×: keeps muscle-protein-synthesis topped up (elevated ~24–48h) + more skill practice. Its real job = it *enables* more quality volume, not growth on its own.
- ● **D1·4** — Sets-per-session has a ceiling (~4–8 hard sets/muscle) before junk volume. This is what forces splitting: weekly volume ÷ per-session cap = required frequency.
- ● **D1·5** — Rest *between sets* protects performance/volume quality: compounds ~2–3 min, isolations ~1–1.5 min. Short rest just costs you reps.
  - ● **D1·5a** — Does *long* rest (5–10 min) hurt? **No.** Recovery is a saturating curve: ~90% back by ~3 min, ~100% by 3–5 min, flat after. Too *short* = lost reps (real cost); *longer* than optimal = no performance or hypertrophy penalty (the "short rest grows more" myth is dead — long rest grows equal/more by preserving volume). Only real costs = **time** (session balloons) + trivial cool-down past ~10 min. Heavy compounds benefit from the longer end (3–5 min); isolations recover in ~1 min.
- ● **D1·6** — Rest *between sessions* for the same muscle ~48h (24–72h): recovery + supercompensation. This constraint is why splits exist.
  - ○ **D1·6a** — Faster-recovering muscles (side delts, abs) tolerate more frequency; heavy-compound-worked ones (low back, hams) need more.
- ● **D1·7** — Splits are the scheduler that satisfies all of the above at once (volume + ~2× frequency + 48h recovery + no shared-function interference). Days available → split choice. (Covered in depth earlier in chat.)
  - ● **D1·7a** — **Is PPL a good *beginner* template?** Meta-logic (pick a template, don't experiment with splits, stabilize fundamentals first) = **yes, correct.** But PPL is the wrong *choice* for a true beginner: 3-day PPL = only **1×/wk** frequency (bad for growth AND for form-practice while learning). 6-day PPL fixes frequency but is a big commitment/volume load. **Best beginner template = full-body 3× (or upper/lower 4×):** 2–3× frequency, low per-session volume, recoverable, forgiving of missed days, fewer movements to master at once. PPL is an *intermediate* tool → migrate to it once form is automatic and you'll train 5–6 days. Rule: days available picks the split (3→full body, 4→upper/lower, 5–6→PPL).
    - ● **D1·7a.1** — **User meant 6-day PPL.** That gives **2× frequency**, so it's a legit, effective template — not a mistake. Objection shifts from frequency → **sustainability**: only 1 rest day (recovery/sleep/food must be dialed), consistency risk (6 days is a big habit + competes with his other pursuits — a 6-day plan hit 4 days is worse than a 4-day plan hit fully), and volume-creep temptation. **Key:** you don't *need* 6 days for 2× — **4-day upper/lower delivers the same 2× frequency with 3 rest days and more forgiveness** = lower-risk route to the same benefit. Verdict: run 6-day PPL only if you'll truly sustain it (good recovery + modest volume); otherwise 4-day upper/lower. **Consistency > optimality.**
  - ● **D1·7b.1** — **Does 4-day U/L match 6-day PPL results?** Yes, at his level. Per muscle it's *identical*: both = 2×/wk, and to hit 12 sets/wk you do 6 sets/session×2 in **both**. Only difference: an upper day holds *more muscle groups* → sessions are **longer/broader**, not harder per muscle. Caveat: tail-end exercises get slightly more within-session fatigue (mitigate by ordering priority first). 6-day PPL only wins at **very high (advanced) volume** where spreading avoids marathon sessions — not his situation. Verdict: same results + far more sustainable for his schedule (weekends flexible, can make up a missed weekday) → **U/L is his split.** Volume you *hit* > volume you *planned*.
  - ● **D1·7b** — **How full-body & upper/lower are built.** *Full body 3× (Mon/Wed/Fri):* whole body each session, ~1 exercise/muscle (2–4 sets), rotate exercises across the 3 days; each muscle 3×/wk (~1×3×3≈9 sets/wk). Shortest sessions, most form-practice, most forgiving → best beginner split. *Upper/Lower 4× (U/L/·/U/L):* split into Upper (chest, back, delts, arms) + Lower (quads, hams, glutes, calves, abs), each half 2×/wk → each muscle 2×/wk (~2 exercises × 3 sets × 2 days ≈ 12 sets/wk); two upper days can differ (chest-focus vs back-focus). Same 2× frequency as 6-day PPL but with **3 rest days** + balanced sessions. Compare: full-body = 3×/wk tiny doses/most flexible; U/L = 2×/wk moderate doses/3 rest days; 6-day PPL = 2×/wk but 1 rest day & 6-session commitment.
- ● **D1·8** — **Volume math made simple (anti-overwhelm).** Count *every* working set that hits a muscle in a week, summed across **all exercises and all days** = that muscle's weekly volume. Aim ~12. **Regions (upper/lower) are exercise-selection, NOT separate budgets** — the pec is one muscle; pick upper-biased moves for emphasis, don't run a second 12-set budget for "upper."
  - ● **D1·8.1** — Dead-simple template: **2 movements × 3 sets × 2 sessions = 12 sets/week per muscle.** Exceptions: triceps & front delts need *less* direct (fed by pressing); side delts take the full amount or more.
  - ● **D1·8.2** — Fix to the user's confusion: chest ≠ "incline only" (that was 6). Count incline + flat + fly across both days (~12–16). Side-delt example (2 ex × 3 × 2 = 12) was already correct.
- ● **D1·9** — **Per-muscle weekly volume ranges** (start at low end; template 2×3×2 already lands most). Chest 10–16 · front delts 0–6 direct · **side delts 12–20** · **rear delts 12–18** · lats 10–18 · mid-back 10–18 · traps 10–18 · biceps 8–14 · triceps 6–12 direct · quads 8–16 · hams 6–14 · glutes 8–16 · calves 10–16 · abs 8–16.
  - ● **D1·9a** — **The heuristic behind the table (it's NOT size).** Baseline **~10–14 sets** for every muscle, then adjust by two factors: **(1) indirect volume received** — muscles fed by your compounds (front delts, triceps, biceps, traps) need *fewer* direct sets; **(2) fatigue/recovery per set** — low-fatigue small muscles recover fast → higher ceiling. The two align: compounds *miss* side/rear delts + calves AND those are low-fatigue → give them *more* (14–20); compounds *feed* triceps/front delts/biceps/traps → *less* direct (6–10). Everything else sits at baseline. Size is a red herring (side delts small→most; quads big→moderate).
    - ● **D1·9a.1** — **Axis model + two fixes.** Picture a 6→20 line; start at 10–14; slide down if compounds hammer it, up if they miss it. Fix A — which lift feeds what: **presses → front delts + triceps; pulls → biceps** (+forearms, some rear delt); **rows/deads/shrugs → traps + lower back**. (Triceps are a *pressing* muscle, not fed by pulls.) Fix B — the high end (14–20) needs **BOTH** "missed by compounds" *and* "recovers fast/low-fatigue." Counter-example: **lower back** is missed by isolation but hammered by deads/squats/rows AND high-fatigue → stays **low** (0–6 direct), don't push it high.
- ● **D1·10** — **Think in ranges, not fixed numbers** (gym + life). Volume is a band: floor (MV) · sweet spot (MAV) · ceiling (MRV). Life/consistency = a *rate*, not a perfect streak: 26/30 is excellent; one lapse ≠ failure (avoid the "what-the-hell effect"). Poker parallel: judge decisions by EV over many hands, don't tilt on one. **Two refinements:** (a) a range still has a **defended floor** — don't let it drift down ("never 2 misses in a row / never <~80%"); (b) a few domains are near-**binary** (addiction relapse, safety) where the floor ≈ the target — don't rationalize those as ranges.

### D1·11 — Split as a function (the automation kernel)
- ● **D1·11** — **`split = f(days, level, volume)`; for a beginner with level & volume fixed → `split = f(days available)`.** What the function really does: distribute a *fixed* weekly volume (~12/muscle) across N days while keeping **~2× frequency** + functional grouping. Volume is constant; only the *packaging* changes.
  - ● **D1·11a** — **Lookup:** 2d→FB×2 · 3d→FB×3 · 4d→**U/L×2** (default) · 5d→U/L×2 + 1 full-body/weak-point (awkward — round to 4 or 6) · 6d→PPL×2 (or U/L×3). Generating rule = **keep every muscle ≥2×/wk** (that's why fewer days force fuller-body sessions; 3d can't be PPL or freq drops to 1×).
  - ● **D1·11b** — **Hold constants constant:** flex the *schedule* weekly as days change, but keep **exercise menu, per-muscle volume, effort (2 RIR), and progression** stable — else the logbook & form-learning break. Days flex; movements/volume/progression don't.
  - ● **D1·11c** — **Degenerate weeks are valid:** a 1–2 day week = full body ×1–2 → at least **maintains** (MV floor). Function never breaks; it just outputs "maintain" instead of "progress." ← This *is* the gym-workout-automation kernel.

### D1·12 — Biasing a region (upper-first) & PPL vs U/L for emphasis
- ● **D1·12** — **PPL splits by movement pattern** (push / pull / legs — upper is pre-split into two); **U/L splits by region** (whole upper / whole lower). User's insight (correct): **PPL decouples upper from lower**, so you can run push/pull *more often* than legs → biases upper *naturally*. U/L yokes upper & lower to similar frequency.
  - ● **D1·12a** — U/L *can* still bias upper, just less elegantly: run more upper days (Upper/Lower/Upper/Upper = upper 3×, lower 1×) or fewer sets on the lower day. So PPL isn't the only way — it's the cleaner way.
  - ● **D1·12b** — Goal "upper first, legs later" is valid (matches his Body Structure priorities). BUT "later" = **maintain** legs, not zero: growth needs ~2×/wk, **maintenance needs ~1×/wk** (or less). So **grow upper (2×), maintain legs (1×)**. True zero for months → detrain + imbalance.
  - ● **D1·12c** — Upper-emphasis templates: **5d = Push/Pull/Legs/Push/Pull** (upper 2×, legs 1×) ✓ clean; **4d = Push/Pull/Push/Pull + short weekend legs** (occasional zero-legs week OK, not the norm). **Revision of earlier:** U/L = simplest/most sustainable, but since he has an upper-first *goal*, **PPL serves better** (free upper-bias lever). Split choice depends on priority: simplicity → U/L; upper emphasis → PPL.

## D2 — How volume distributes across muscles *within a day* (first principles)
- ● **D2·1** — **Misconception killed:** a day is **NOT** about even sets across its muscle groups. Evenness would over-serve compound-fed muscles and under-serve the missed ones.
- ● **D2·2** — Real principle: each muscle gets **its own** weekly target (per D1·9), and per-session = target ÷ frequency. The day is assembled muscle-by-muscle, not split into equal shares.
- ● **D2·3** — **The shaping principle: subtract indirect work.** `direct sets = weekly target − volume already received indirectly from compounds`. Push day: chest = most (prime mover + focus); **front delts = 0 direct** (pressing covers them); triceps = *top-up* only (partly fed by pressing); **side delts = full direct** (pressing misses them). Reframe: the set target belongs to the **muscle by its role** (prime mover = full target; synergist = reduced; missed = high), not to "the compound movement."
  - ● **D2·3a** — **Triceps direct volume = 6–10 (lean ~6–8), NOT 8–12.** They're heavily fed by ~12 pressing sets/wk on push day, so direct work is a top-up. **Nuance:** pressing hits lateral/medial heads; the **long head** (crosses shoulder) is under-served → include **overhead extensions** (long-head/stretch).
    - ● **D2·3a.1** — **Correction: NOT overhead-only for a beginner.** Theory says overhead covers the missed long head, BUT user *can't feel* overhead (elbow flare) and feels **pushdown perfectly** → an exercise you can't execute gives poor stimulus. So **keep pushdown as the anchor** (loadable, felt, progressible = quality work) and **add overhead as the lighter long-head + skill movement.** Run both at low total (~6–8/wk): both light each day, or alternate (pushdown day A / overhead day B). Trajectory: as overhead skill improves, shift more quality onto it (better long-term stimulus). Today pushdown = workhorse, overhead = apprentice.
- ● **D2·4** — Order by **priority + dependency**, not evenness: priority/big compound first (chest) → muscle that limits nothing (side delts) → assistor last (triceps, the pressing weak link).
- ● **D2·5** — User's push day is correctly **uneven** (chest 3 moves / side delts 2 / triceps 2 / front delts 0) → that lopsidedness = proof it's right. Watch: 2 direct triceps + heavy pressing may tip triceps slightly over range → trim a set if elbows complain.
- ● **D2·6** — Both push days: **similar volume, rotated exercises/angles** (incline-focus vs flat-focus) for regional coverage + variety.
- ● **D2·7** — Summary: build a day by topping each muscle up to its *individual* target (accounting for indirect work), then order by priority/dependency. Not "spread evenly," but "fill each to its own target."
