Length, time & cost — what to expect

Want a short answer?

Say so — “in 3 bullets,” “one line.” There's no magic toggle; length is set by your prompt.

Deep reasoning costs time

Chain-of-thought & extended thinking lengthen output and latency. Use them for hard tasks, not every task.

Cowork > Chat in cost

The agentic loop burns more usage. Batch related work into one session; use Chat for the trivial.

Auto mode costs more

Per-action safety screening in Auto mode uses more usage than Manual or Skip.

🔐

Permission modes & safety gotchas

Manual

Asks before each action. Most oversight, slowest.

Auto

Screens each action, blocks unsafe ones — costs more usage.

Skip

No checks. Only when you fully trust every step.

⚡ Live artifacts use your approved connectors WITHOUT asking — even in a mode that would normally require approval. Careful with connectors that can change data.
⚡ Computer use has no sandbox between Claude and your screen. Use a dedicated folder, blocklist sensitive apps, close them first.
⚡ Deleting a file always needs explicit permission — in every mode. That one is never skipped.
⚡ Egress doesn't gate web search/fetch or MCP — those run outside your network policy. Team/Ent owners can disable web search & Chrome.
