## Tips
- Leave labels OUT of the prompt — AI text rendering is unreliable. Add
  "Meditation / Swimming / Gym / Fashion / Social Mastery" afterward (I can overlay them).
- Aspect ratio: MacBook Air M4 is 2560×1664 (~1.54:1). Use `--ar 16:10` in Midjourney;
  ask for "16:10 / 1.6:1 wide" elsewhere. Upscale to 2560×1664 for a crisp wallpaper.
- Keep "consistent art direction across all panels" in the prompt so the five scenes match.
- For a softer storybook feel add "watercolor, gentle"; for punchier manga add "high
  contrast ink, screentone, dynamic".
